Tech Stack (recommended, swappable)

  • CMS / brand site: Squarespace (existing) - keep modernmind.earth on Squarespace, deploy bio funnel as a sub-page or subdomain
  • Cohort landing: Custom HTML deployed to a sub-page or Webflow if more design control needed
  • Email: Kit / ConvertKit (preferred for creator audiences) - clean API for quiz integration
  • Quiz: Typeform (preferred for the soft-feminine UX) or ScoreApp if scoring math gets complex
  • Payment: Stripe (cohort) - existing Whop / Skool stays for Portal subscription
  • Course / membership host: Skool (existing for The Portal) - cohort runs as a private Skool group within or alongside the Portal
  • Video host: Wistia (cohort + VSL) + YouTube (long-form podcast) + Loom (1-to-1 personal video reviews if she keeps premium tier)
  • Analytics: GA4 + Meta Pixel + Microsoft Clarity (heatmaps) + Pinterest Tag (wellness audience)
  • CRM: Kit segmentation (light) - GHL only if outreach/sales pipeline grows
  • Scheduling: Calendly (default) or Cal.com
  • Project / build: Notion (handover-friendly)

Integration Points

  1. Quiz → Email · Typeform triggers Kit on completion with archetype tag
  2. Email → Cohort apply · Kit triggers Stripe checkout link for archetype-A path
  3. Email → Portal trial · Kit hands archetype-B subscribers to Skool trial offer
  4. Book purchase → Email · Amazon affiliate / book funnel form captures email pre-Amazon-click; post-purchase confirmation unlocks chapter-mapped sequence
  5. All events → GA4 + Meta Pixel via GTM · captures full funnel attribution
  6. Podcast CTA segment → modernmind.earth/start · standardised end-of-episode CTA tracked via UTM

Owner Map

  • Amber: filming (VSL + photoshoot day), live cohort calls (1 per week x 8 weeks per cohort), monthly podcast CTA segment, top-line decisions on copy + brand
  • AG1 (Andrei): everything else - landing page build, email writing, quiz build, automation setup, content production cycles, ads management once Phase 4 activates, weekly reporting

Failure Modes + Mitigations

  • VSL filming delay (Amber NZ-based, time zone reality) → use existing Modern Mind Podcast audio + soft B-roll as the Phase 1 stand-in; replace with custom VSL by end of Phase 1
  • Book funnel pre-Amazon capture friction → start with post-purchase trigger only (book buyer email captured at Amazon order ID lookup or via "register your book" landing page); pre-Amazon capture is a Phase 2.5 enhancement
  • Cohort fill rate dependency on waitlist size → pre-launch warm waitlist via existing Executive Coaching list before opening to broader IG audience; soft launch to 20 seats first to validate
  • Squarespace + custom subdomain integration → if Squarespace constraints block sub-page deploy, host bio funnel at modernmind.earth/start as a separate static site behind a CNAME; functional, no SEO penalty

KPIs (90-day)

  • Phase 1 · Magnetic Method Cohort landing live · 20-40 seats filled in first cohort
  • Phase 2 · 1,000+ quiz completions · 8-15% IG-bio-click → email conversion
  • Phase 3 · 40+ short-form posts shipped · 4 long-form podcast episodes published with CTA segment live
  • Phase 4 · Meta CPL under $35 (wellness-niche benchmark) · ROAS 3x by week 12
  • Year-1 floor target · $315-720K incremental on top of existing Portal, book, app, and Executive Coaching revenue
